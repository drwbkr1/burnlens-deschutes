## U03 — accessibility, rendered-browser posture, and reviewer clarity

Source inspection found one degraded-mode defect in the canonical interface:
the rejected U-Net SVG group did not carry an initial `hidden` attribute.
JavaScript hides it during normal initialization, but disabled or failed
script execution could expose the diagnostic even though the interface says
it is off by default.

the verified Phase Four bytes unchanged. It:

- hides the rejected model in the HTML before any script runs;
- adds a focusable main-content skip target;

  equivalent available;
- adds a four-step first-time reviewer path and the exact U02 failure result;

  reduced-motion behavior, and the strict offline CSP;
