# Evidence wins; the model does not

The Phase Six entrypoint now renders the project’s real conclusion instead of
burying it in chronology. A 30-second scan shows RBR at 1.000 selected-core
macro Dice, the U-Net at 0.299 and rejected, WCP-001’s strong MTBS overlap, and
WCP-002’s 66.76 ha false-positive-risk result.

The page is static, local, and deliberately compact. It uses no script or
external asset. Nine exact links lead back to the accepted baseline, rejected
model, Ward Creek interface, immutable packages, known issues, reviewer
journey, and case study.

The first rendered draft exposed a subtle keyboard issue: its skip link
scrolled correctly but did not transfer focus away from the body. The final
surface gives the main evidence landmark native programmatic focus. Desktop
and 390-pixel Edge QA, keyboard activation, all links, claims, privacy, and
source notices now pass.

This is still a local pre-publication surface. Packaging, recipient QA, release
audit, and every public action remain later gates.
